## Why

People see two layout versions in Finder and cannot tell which data is live. Empty service recovery directories survive a successful move. Desktop notifications maintain their own copy of embedded artwork.

## What changes

Use stable categories for sessions, HQ, attachments, services, diagnostics, backups and cache. Keep the on-disk format version in verified metadata. Doctor inspects first and presents an offline move only for an identified older store. Recovery of interrupted transactions precedes cleanup. Preserve fixed locks, known attachment references, socket identity and input deduplication across versions.

## Surfaces

- Terminal: Doctor owns inspection, consent, interruption recovery and verification.
- Menu bar: consume the same icon files and notification queue as the CLI.
- Phone: existing attachment links and input acknowledgments remain valid.
- iPad: the same host protocol and access checks apply.
- Web: use embedded icon bytes and preserve registered preview identities.
