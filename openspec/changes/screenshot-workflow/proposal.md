# Screenshot workflow

Preserve independent screenshot documents while allowing another capture. Use the menu-bar session title, searchable keyboard selection and precise non-approval refusal feedback. Keep native target/approval/draft guards and uncertain-delivery semantics. No live session restore, permission changes or deployment.

## Surfaces

- terminal: CLI screenshot edit handoff opens another independent document up to the same bounded window limit; protocol version and permission/descriptor contract stay unchanged. Native input unknown-state refusals remain fail-closed.
- menubar: independent screenshot windows, menu-bar session titles in the searchable keyboard picker, precise bilingual refusal feedback and content-free diagnostics.
- phone: no screenshot editor UI change; native input still refuses unknown states, without changing remote authorization or retry channels.
- iPad: same shared input boundary as phone; no new editor or layout in this Mac-only change.
- Web: no browser screenshot editor change; existing native input and delivery protections remain.
