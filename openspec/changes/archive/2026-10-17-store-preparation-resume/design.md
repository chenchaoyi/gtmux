# Design

Build artifacts contain only an unsigned simulator application and provenance. Reuse is limited to completed manual runs of this same workflow on main. Source, Xcode, architecture and tree hashes must match. Capture checkpoints hold independently completed device/language groups with file hashes and the complete app/harness/runtime context. Failed or mismatched groups are never considered complete. Rendering uses reviewed current scripts/captions and released widget source; its manifest retains capture and rendering identities separately.

Store upload gates compare every signed package against a verified original IPA or archive, permit the Store beta-reporting difference (plus debugger-off and production-APNs transitions for development-signed archive baselines), check Store profiles and exact identity/version, and preserve resource hashes/native UUIDs. Archive-backed verification requires matching dSYMs. Checks run before fastlane upload. Recovery excludes provisioning profiles, signing setup and symlinks and is encrypted using the existing operator-held recipient.

ASC helpers flush progress immediately and retain a private append-only event journal. Processing expiry is a pending result, not permission to upload duplicates or replace placements with unready images. Independent readback compares local text, screenshot order/content identities, creative placements, VALID selected build and package receipt; only all passing checks yield ready_for_user_review. Final preview/Submit remain user actions.
