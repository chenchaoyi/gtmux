# Design
Use a compact desktop assistant with a shared header and action footer. Selection and
preview size to their content; staged review gets a bounded sidebar/detail workspace.
File name is primary, containing folder secondary. Read only a bounded header for UI
password presentation; Go remains authoritative for format, decryption and validation.
Cancel closes the flow; archive change returns to selection and resets choices. Enter
advances only enabled actions, Escape cancels; busy operations disable dismissal.
