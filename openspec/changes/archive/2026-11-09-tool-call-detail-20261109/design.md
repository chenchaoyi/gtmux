# Design

Use optional ToolCall metadata and a native detail ref. Full bodies are allocated only by the existing scoped reader. A result fingerprint binds the ref to the recorded completion; mirrors enrich the original call without changing its selected input/ref. Poll cache accounting includes metadata only.

The canonical toolPresentation module supplies labels, parameter rows, result sections, raw envelope and safe display paging to RN and generated Web. Renderers retain existing code readers and text-only insertion. The full source remains copyable. Missing data, empty results and read failures differ. Recognized structured credentials and binary MCP blocks are filtered on the full path and marked. Free-text redaction is not promised.

The reviewed TCV test plan precedes test edits. Synthetic parser, component and browser tests cover observable values, boundaries and regressions; read-only Go overlays preserve exact baseline negative-control source.
