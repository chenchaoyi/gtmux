# 对话复制反馈与小范围辅助功能改进

## 原因

iOS 对话段落长按后出现复制菜单，却没有标明复制范围。React Native 0.86 的 Fabric 段落只提供整块复制，没有范围选区；调整 selectionColor 无法补出高亮。此外，HQ 卡片和答复选项把测试编号当作读屏名称，违背现有规范。商店尚未填写辅助功能声明。

## 改动

- 保留整块复制范围和 Markdown 渲染。仅在对话视图中增加 iOS 原生菜单包装层：菜单打开时高亮对应文本块；菜单关闭、文本更新或视图移除时清除。Android 范围选择和旧安装包回退保持原行为。
- 为 HQ 与答复选项提供中英文操作名称和按钮角色，测试编号保留在 testID。
- 记录基于商店当前版本的保守评估流程，按设备类别分别核验后声明。辅助功能说明网址可留空，本轮不扩大为完整 VoiceOver 或大字体适配。

## 界面范围

- phone、iPad：共用对话复制反馈与控件读屏名称，商店能力分别评估。
- menubar、terminal、Web：不改变渲染、会话或文本选择机制。

## 验证

JS 回归覆盖复制范围、行内链接、外部布局、非对话原有渲染、辅助操作与投递/测试标识。隔离 UIKit 检查覆盖高亮与菜单生命周期、复制内容、重复操作、迟到回调、流式更新及移除。现有 iOS CI 编译完整 App 与扩展。源码和模拟器检查不能代替真机 VoiceOver 验收。
