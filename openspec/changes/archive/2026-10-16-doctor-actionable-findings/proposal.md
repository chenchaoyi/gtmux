## Why
Doctor findings currently offer a link back to the same check instead of a useful next step. Save health also mistakes an unchanged resurrect layout for a stopped saver, and conversation-binding guidance overstates a heuristic.

## What changes
- Present complete, selectable finding guidance with specific safe actions: copy the diagnostic command or open HQ. Keep repair review explicit and interactive.
- Record bounded, server-scoped successful save evidence; distinguish save execution from snapshot changes. Missing or invalid layouts cannot pass.
- Describe possible binding mismatches as unconfirmed and use direct bilingual copy.

## Surfaces
- CLI (terminal): corrected health evidence and guidance; additive JSON action metadata.
- Menu bar (menubar): self-contained findings and specific actions instead of scroll-back links.
- phone: no environment-report UI; no change.
- iPad: no environment-report UI; no change.
- Web: no environment-report UI; no change.

## Non-goals
No automatic binding changes, repairs, live plugin edits, release or installation. No assertion that a successful save script verifies every restored process or pane capture.
