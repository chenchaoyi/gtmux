# Provenance does not grant control

Keep the existing creation-origin check and admit the two observed string
sources. Unknown values, missing sources, subagent objects and non-TUI origins
remain ineligible. The subsequent verifier still requires the callback PID to
match the stable, interactive foreground client. It must not substitute the
ancestor or PID of a shared app-server. No conversation, consent, process or
client configuration is changed by this compatibility adjustment.

Synthetic regression coverage includes both sources, editor/desktop origins,
unknown sources, subagents and a shared backend with a different frontend PID.
This does not establish automatic frontend discovery for a multiplexed daemon.
