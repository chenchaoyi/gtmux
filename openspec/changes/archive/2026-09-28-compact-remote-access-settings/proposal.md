# Make remote access settings easier to scan

## Why

In Preferences, the Access and Connection method choices appear centered below
left-aligned labels. The Direct route list then starts at a third edge. Two extra
lines repeat the selected method and expose a raw URL in the middle of settings.
This makes three related choices feel like unrelated blocks.

## What changes

Keep Access, Connection method, and Route in that order in both Mac windows.
Give each choice one aligned, full-width control; keep the selected server in
the Route row. Put optional explanations and the current address behind a
clickable help control in Preferences. The pairing code card still shows the
address directly, where it is used.

## Surfaces

- **terminal**: no change.
- **menubar**: Preferences and Pair your phone share the revised controls.
- **Phone / iPad / Web**: no change.
