## Information hierarchy

Full reply text stays primary. A grey summary discloses a compact icon-led list; only recorded input/directory/partial-detail content creates a second control. No state implies a call succeeded. Copy/share/fold follow the last text, before trailing tools. Claude Code Normal and Carbon disclosure guidance inform the hierarchy, as recorded in the bilingual activity research.

## Profile requests

A reusable keyed/abortable read hook derives loading before effects, prevents stale-target data, and supports explicit retry. The agent dialog keeps a stable body height during initial loading and uses compact identity/provenance rows. Historical facts still use exact source/time. On explicit chain expansion, a separate current request is allowed only for a matching source session; only verified chain/time render, never current model/tier/effort. Header profiles reuse their existing current response. Cross-session/agent results are rejected; other senders and stitched older sessions get no runtime fallback. No backend change, background polling, process scan or new permissions.
