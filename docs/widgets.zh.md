# 用量小组件

iOS/iPadOS 17 及以上可在系统小组件库中添加 **Agent 用量**。主屏幕支持小号、
中号，显示服务商额度或钱包余额；锁定屏幕支持圆形、矩形和单行。实时活动仍是
独立功能，沿用原有系统版本支持。

添加后先打开一次 gtmux，配对并选择拥有完整访问权限的服务器，再返回主屏幕。
点击小组件会打开该服务器现有的用量页面，不需要先启动 HQ。访客分享不能提供
小组件的用量数据。

**自动**优先显示当前服务器使用比例最高的有效额度，中号可同时显示两项读数，新的读数排在旧读数前面。
编辑小组件可以指定 Agent；选项来自实际取得的读数，也支持自定义服务商。
如果指定的服务商不再有数据，会显示暂无读数，不会悄悄切换成其他服务商。
切换服务器会跟随 App 的当前选择，小组件不单独保存另一份连接。

额度百分比表示**已用**。DeepSeek 余额保留来源的币种和钱包类型，不合计不同
账户、币种或钱包。缺少读数不代表余额为零。生成新快照时会排除历史额度和已经
到达重置时间的窗口；缓存中的窗口到达重置时间后会显示等待更新，不会自行推算
额度已经恢复。

小组件显示读数时间，超过 15 分钟会标为上次读数；锁屏的紧凑样式也会区分旧数据。
大字号下，小号组件使用紧凑排版，确保 Agent、主要读数和更新时间能完整显示。
完整详情可点击进入 App 查看。

## 刷新与隐私

仅在已经添加用量组件时，主 App 才会在前台定期每分钟更新；进入前台或切换连接
时会重新核对，并申请最早 15 分钟后的后台刷新。实际后台执行和组件重绘由系统调度；休眠、低电量、
强制退出、凭据暂时不可读或服务器不可达，都可能延迟更新。这里展示带时间的
读数，不代表实时连接，也不预测账单或未来用量。

扩展从 `group.com.gtmux.app.usage` 读取有大小限制的展示快照，只包含服务商名称、
额度窗口、钱包金额、服务器显示名称和时间。不包含配对令牌、服务器地址、
服务商账户标识、对话或会话历史；扩展不编入主 App 的钥匙串读取器和网络客户端。

主 App 使用原有私有配对存储，保留原有保护方式。请求用量前先确认完整访问权限，
拒绝 HTTP 重定向，限制响应体积和请求时间，连接变化后丢弃旧响应。
断开连接、选择访客连接、移除配对或收到授权拒绝后，会清除共享快照。
若受保护凭据暂时不可读，则保留带时间的旧读数。组件内容标记为隐私敏感数据，
具体隐藏时机由系统隐私与锁屏设置决定。

## macOS 与后续交付

快照模型、格式化和 SwiftUI 视图已支持在 macOS 14 及以上编译，可供后续原生
Mac 扩展复用。**本次尚未安装原生 macOS 小组件。** Apple 的 iPhone 小组件连续
互通是另一项系统能力，不能算作 gtmux 已实现原生 Mac 扩展。

当前 Mac App 通过 Developer ID 签名，以 SwiftPM 应用包直接分发。原生组件还需要
独立沙箱目标、嵌入、签名、公证验收和可用的共享容器。Apple 推荐的 `group.`
容器方式在 macOS 上需要 provisioning profile，即描述应用权限与签名关系的配置文件。
启用原生扩展前，需要结合现有 Mac 打包流程验证这些前置；不能用未签名扩展，
也不能把配对凭据复制到共享容器来代替。

下一次 iOS 签名交付前，主 App 和 `GtmuxWidget` 的应用标识都需要启用同一个
App Group，并使用与权限一致的配置文件。导出校验会核对共享容器权限是否获包内
配置文件授权；旧源码中没有共享容器的包仍可验证。通知扩展不加入该组。模拟器无签名编译
不能证明开发者后台能力已登记、配置文件正确、后台刷新准时或真机安装成功。
本次源码开发不改变已经提交审核的旧包。

## 实现位置与参考

- `shared/UsageWidgets`：展示模型、快照存储和视图，另设仅供主 App 使用的网络目标；
  Swift 测试覆盖真实本机 HTTP 请求和快照的数据边界。
- `mobileapp/ios/UsageWidgets`：主 App 刷新协调器、React Native 轻量接口与系统组件配置。
  Xcode 注册脚本将凭据读取器和传输代码限定在主 App 目标中。
- `mobileapp/src/usage`：连接变化处理，以及唯一的 `gtmux://usage` 用量入口。

展示方式参考 [Moshi 的 Agent 用量文档](https://getmoshi.app/docs/agents-usages)。
平台行为依据 Apple 的[可配置小组件](https://developer.apple.com/documentation/widgetkit/making-a-configurable-widget)、
[刷新预算](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date)与
[App Group 容器说明](https://developer.apple.com/documentation/xcode/accessing-app-group-containers)。
