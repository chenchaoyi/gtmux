# 将 HQ 迁移到另一台 Mac

## 恢复还是迁移

菜单栏 **HQ → 知识库 → 导入…** 位于“导出”旁，提供三个入口：

- **恢复 HQ 备份**：恢复整份档案，包括旧态势板和内置规则；当前 HQ 目录另存为备份。
- **从另一台 Mac 迁移**：选择长期内容，迁入当前 HQ。
- **继续核对暂存内容**：关闭窗口后，重新打开核对流程。

这些流程已实现。`gtmux hq --import` 仍是整份恢复，并非选择性迁移。Mac 导出的加密档案和
手机/iPad 导出的未加密 `.tar.gz` 副本均可作为来源。未加密副本需在界面明确确认；CLI 暂存
需加 `--allow-plain`。口令在本机输入，通过标准输入交给 CLI，不放入命令行参数。

选择备份和预览使用紧凑窗口；先选文件，加密备份才显示密码框。是否加密根据文件头判断，
不依赖扩展名，完整校验仍由 CLI 执行。取消、上一步和当前主要操作集中在底部。知识与
个人要求核对页展开为列表详情或并排对照布局。操作进行中不能关闭窗口。

## 哪些内容可以迁移

| 内容 | 处理方式 |
|---|---|
| 知识台账 | 可选；包含当前在库条目及其修订链需要的历史、来源快照。应用前核对。 |
| `LOCAL.md` 个人要求 | 可选；与当前全文并排比较，默认保留当前内容，替换需单独决定。 |
| `knowledge/tools/` 工具附件 | 可选；仅私有暂存，并移除执行权限，不自动安装或运行。 |
| 态势板、会话、待整理线索、无关的退休条目、其他笔记、内置规则及生成的分发文件 | 不迁移，在新环境重新建立。 |
| 连接凭据、配对 token、隧道账号和权限状态 | 不迁移，在新 Mac 重新授权。 |

所有选项默认不勾选。条目及其历史曾标为敏感的，只有明确选择敏感内容才会进入暂存。
主题、种类和旧分发范围不能证明知识适用于新机器；接受前需核对路径、环境事实和授权范围。

## 核对与应用

1. 选择档案，加密档案需输入口令。预览会完整校验文件，显示知识数量、敏感数量、个人要求
   是否存在及工具附件数；不写入 HQ，也不推测来源中没有的创建日期。
2. 选择内容并暂存。版本化清单、内容摘要及选中的文件私有保存于 gtmux 状态目录下的
   `hq-migrations/<ID>/`。
3. 在右侧详情区核对知识全文，选择条目并确认适用于这台 Mac。同 ID 的不同历史属于冲突，
   不允许导入。完整来源历史已存在时跳过，包括本机后来退休或修订的历史，不复活旧条目。
   部分历史重叠也会拒绝，不自动合并。
4. 应用或恢复前需退出 HQ，空闲也不算退出；活着的 agent 仍持有旧上下文，可能覆盖新内容。
   不自动轮换或向 pane 输入。HQ 启动、恢复和应用共用锁；并发操作会明确报错，不长期等待。
5. 所选知识通过一次原子台账替换提交，并保留私有的合并前备份。原 ID、操作历史、中英文
   正文及来源快照保留，导入操作带有来源档案摘要。追加撤回记录，清除旧分发范围、晋升和
   落地决定；导入后先供 HQ 使用，分发另行决定。已有同名主题的定义沿用，不覆盖。
6. 个人要求单独应用：比较两份全文，明确选择替换，并保留私有备份。目标在预览后发生变化
   时，摘要校验会拒绝替换，需重新核对；相同正文则跳过。知识和个人要求分别提交、分别回执，
   不宣称它们属于同一个事务。

回执包含操作/暂存 ID、导入与跳过数量、备份位置及是否已提交。提交前失败不修改当前内容；
知识已提交而视图生成或同步失败时，会明确报告已提交，应执行 `gtmux knowledge render`
修复视图，避免再次导入。诊断和事件日志记录 ID 与数量，不记录口令、知识正文或个人要求。
来源中的会话、事件序号和路径仍是**旧 Mac 的证据**，不能当作本机事件引用。

## 校验与限制

移动当前 HQ 目录前，会校验完整 tar/gzip/age 文件。限制为：档案及解压后总量 128 MiB、
单文件 32 MiB、档案条目 5,000、知识记录 50,000，age scrypt 工作因子上限 18。不安全路径、
规范化后重复路径、链接/特殊文件、校验失败、不支持的台账操作、未知字段及无效修订链均明确
失败。核对和应用时再次检查暂存路径与摘要；暂存目录私有，文件无执行权限。

只有旧 Markdown、没有台账的档案仍可整份恢复，也可暂存个人要求/工具；选择性迁移知识前
需人工整理为台账，不补造事实或来源。冲突 ID 留待按知识台账流程明确修订，不覆盖以求完成
迁移。暂存附件和备份会保留，此功能不自动删除。

## 各端范围

Mac 菜单栏提供文件选择与核对流程；`gtmux hq migrate --help` 提供相同的本机核心能力。
手机和 iPad 保留整份副本导出，不提供远程导入。Web 不新增档案权限或导入接口。无需账号、
服务器或外部记忆服务。
