# 将 HQ 迁移到另一台 Mac

## 先分清恢复和迁移

**恢复这台 Mac** 是丢失数据后还原整份 HQ 档案。现有 `gtmux hq --import` 做的就是这件事：
导入前先把当前目录挪到一旁，旧态势板等内容也一并还原。

**迁移到新 Mac** 只带走选中的长期内容。旧 Mac 的会话现状、内置规则、连接和授权都不应带过去。
因此不能把现有的整份导入命令当成迁移命令。Mac 菜单栏导出的是口令加密文件；手机现有副本
则是未加密的 `.tar.gz`。两者都可作为迁移来源，但分享或选择手机副本时必须明确提示未加密。

## 带走哪些内容

| 内容 | 新 Mac 上的处理 | 原因 |
|---|---|---|
| 知识台账（`knowledge/.ledger.jsonl`） | 可选择迁移 | 经验及其来源值得保留，但关于旧机器的判断要先核对。 |
| 你的要求（`LOCAL.md`） | 可选择迁移 | 长期偏好和授权边界可以延续；应用前要看正文及与新 Mac 现有内容的差异。 |
| 知识工具（`knowledge/tools/`） | 仅暂存待核对 | 脚本可能引用旧路径、凭据或环境；不能到新 Mac 就自动执行。 |
| 态势板（`notes/board.md`） | 不迁移 | 它记录的是旧 Mac 的会话、窗格和待办；新 HQ 应自行建立。 |
| 内置规则（`AGENTS.md`、`CLAUDE.md`） | 不迁移 | 由新 Mac 上的 gtmux 按版本和语言生成。 |
| 其他笔记、待整理内容、待发布的知识简报 | 不迁移 | 它们的进度和目标与旧环境相关；已形成的知识及来源仍留在台账。 |
| 会话和事件日志、快照、机器规则、隧道账号、设备令牌 | 不迁移 | 这些是主机状态或凭据，应在新 Mac 重新连接和授权。 |

现有的 `kind`、主题、读者范围和来源字段都不能单独证明一条知识适用于新电脑。尤其是
`machine` 指的是**旧**机器。预览可以用这些字段提示核对，不能据此自动判定可迁移。
敏感条目在预览中只显示数量，需单独勾选并确认；正文和凭据不能进入日志。

## 用户操作

1. 优先在旧 Mac 用口令导出 HQ 档案。旧 Mac 已无法使用时，也可以把手机上未加密的副本
   导出到「文件」；界面要提示它未加密。这两种档案也都可用于原机恢复。
2. 在新 Mac 打开 **HQ 档案 → 从另一台 Mac 迁移**（命令行对应
   `gtmux hq migrate --from <档案>`），在本地输入口令；未加密的手机副本无需口令，但需
   明确确认其未加密。只读预览显示来源时间、各项数量、
   敏感条目数量和新 Mac 上的冲突；此时不改任何文件。
3. 勾选 **知识库** 和／或 **你的要求**；两项默认都不勾选。选择后者时，先与新 Mac 的 `LOCAL.md` 对比，
   可以保留新 Mac 原有内容。态势板和内置规则直接说明为“留在旧 Mac”，不做成看似可选的灰框。
4. 先导入私有暂存区并验证。如果新 HQ 正在工作，先停止应用，等这一轮结束。验证通过后，
   给目标数据留快照，再写入所选内容；中途失败就恢复快照。
5. 完成页列出已迁入、重复跳过、冲突和待核对的数量，并打开核对列表。新 HQ 根据当前会话
   建立自己的态势板。

## 知识合并与核对

知识台账是追加式的操作历史，不是一堆可以直接覆盖的 Markdown 页面。导入时逐条验证操作，
在暂存台账中保留原 ID、前后关系和来源；主题页面由新 Mac 重新生成。

- 目标已有完全相同的条目和历史时跳过。相同 ID 对应不同内容时列为冲突，不能以后写覆盖前写。
- 导入的条目先标记为**来自旧 Mac · 待核对**。核对前不能派发给 agent、提升为机器规则，
  也不能当作新 Mac 的事实。用户可逐条确认，也可在看过一组内容后成组确认；未确认的继续留档。
- 敏感条目需要单独选择，确认后仍遵守现有敏感知识规则。工具脚本只作为附件暂存，逐个核对。
- 即使新 Mac 的知识库为空，也要走同样的验证和核对；空库不代表旧环境的结论仍然成立。

应用阶段使用有版本号的迁移清单、受限的解包大小、安全路径校验和私有暂存目录。
结构化回执记录迁移 ID 和数量，不记录正文或口令。重复导入同一份档案不会产生重复条目。

## 各端入口

- **Mac 菜单栏**负责选文件、预览、选择内容、处理冲突和显示结果。现有整份导出明确叫
  **导出 HQ 档案作备份**；新入口叫**从另一台 Mac 迁移**。
- **CLI** 提供同一套预览与应用能力，便于在无菜单栏的电脑上操作。
- **手机和 iPad** 继续保留、导出整份副本，并明确提示导出的 `.tar.gz` 未加密；
  可将文件交给新 Mac，不提供从手机远程改写 Mac 档案的入口。
- **网页**不提供档案导出或迁移，分享页面不能获得这类权限。

这份文档是迁移功能的设计。独立的迁移命令和核对流程实现前，现有 `--import` 仍只用于整份恢复。
