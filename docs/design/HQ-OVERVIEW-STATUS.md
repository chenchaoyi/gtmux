# HQ overview: open goals and remaining items

An explicit workspace matter state owns completion. A result body, completed substep, idle worker or saved reply cannot finish the whole goal. HQ reconciles verified final reports and closes genuinely delivered goals; open assessments start with the remaining outcome or blocker, next owner and action. Only a concrete unresolved human action belongs in Needs your input. Engineering blockers remain HQ follow-up, with a clear next step.

The Mac overview shows a bounded three-item preview and a bottom control naming the exact remaining count and displayed/total count. This follows the existing iPhone/iPad/Android footer pattern; it opens the existing full-list picker, not a hidden automatic action. Fully displayed lists have no more control. The picker includes current status and assessment.

Canonical completed, closed and merged records are excluded, even if a cached projection still names them. Missing/duplicate previews are filled from explicit current records. Current assessment takes priority over historical receipt text, without turning metadata update time into an assessment timestamp. Goal status and session status remain separate; unavailable source discovery is not an idle/completed session.

Tests use synthetic snapshots and independent native windows in English/Chinese, light/dark and minimum/wide layouts. In-process AX actions do not establish physical mouse, VoiceOver or installed-product acceptance. Real workspace corrections go through HQ's durable API, never hand-edited records or automatic inference. No release/install or runtime migration is included.
