# Codex 状态以当前对话为准

窗格可能留有另一条会话的具名活动标记。窗口近期有活动，不代表当前会话又开始工作。共享 radar 只有在当前 home/session/cwd 的实时绑定可核、标记明确属于别的会话、当前对话自己的日志已结束、终端已就绪且没有工作/排队/审批证据时，才纠正显示。旧版仅有恢复记录时不能证明独占前端，不触发这项纠正；未知归属和旧版无名标记继续保守处理，真实开始和审批仍优先。

纠正不重绑窗格、不删除标记。界面使用当前对话实际结束时间，不写空闲缓存；保留真实中断原因，也不生成新的或“最新”的完成证明。等待判定使用 hook 覆盖前已采样的画面/CPU 证据，不能把活动标记自己当成新活动。CLI、Mac、Web 和共享手机端消费同一结果。

回归隔离 HOME、状态、日志以及进程/终端边界；不用真实输入、清理动作、对话正文或绑定 token。发现旧标记不等于证明其来源。本轮不发装、不改权限。
