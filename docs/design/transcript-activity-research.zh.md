# 对话中的执行过程展示

英文正本：[English](transcript-activity-research.md)。

用户截图里连续的 `js`、`wait` 没有层次，也没有展示调用自带的描述。问题在展示与信息提取，不需要增加 agent 状态。

## 官方参考（2026-10-19 核对）

- [Claude Code Desktop 的视图模式](https://code.claude.com/docs/en/desktop#switch-view-modes)：Normal 把工具调用折叠成摘要，保留完整回复；Verbose 展示每次调用。借鉴按需展开，不再加一个全局模式选择器。
- [Codex 的活动分组](https://github.com/openai/codex/blob/e4568a3538c9cab6627d64ff8cdfc7d98b79b7db/codex-rs/tui/src/history_cell/activity_group.rs)：相邻调用按顺序组织，活动更新时保留细节的位置。借鉴回复段落之间的有序过程分组。
- [Codex 的终端交互记录](https://github.com/openai/codex/blob/e4568a3538c9cab6627d64ff8cdfc7d98b79b7db/codex-rs/tui/src/history_cell/exec.rs)：轮询和输入记录保留在详细/原始历史中，普通对话不反复打印通知。借鉴紧凑摘要，避免一墙不明所以的工具名。

Codex 参考是其官方开源终端界面，并非检查过的私有桌面实现；Claude 参考来自官方文档。本轮未操作这两个桌面 app，没有复制代码或视觉素材。

## 方案

每段工具调用放在低对比度描边的「执行过程」卡片中，与回复气泡分层。Web 保留工具数量摘要；手机/iPad 改为一行操作摘要与调用数量，展开后是带语义图标的有序列表。读取文件、目录、搜索、命令、编辑、网页、代码、等待与委派各用自己的中性线条图标，未知工具保留通用图标与真实名称。单条再展开工具名、记录的目录和原始输入，同一组同时展开一条；长命令保留换行、支持横向滑动，多行正文有高度上限。整组收起后移除所有列表与详情；复制只复制当前展示的内容。补充视觉参考来自用户 2026-10-20 的活动列表截图，没有重新操作厂商 app。使用中性文字与分隔线，不用青色工具名墙，也不凭调用存在就画成功勾。手机/iPad 延用执行中默认展开、历史默认折叠、用户选择优先的规则；Web 专注对话保留默认折叠；工作台紧凑小窗仍只显示回复。

Codex 优先取字符串 `title`，再取 `description`，否则沿用命令/路径等字段。仍合并空白、限制为 80 个 Unicode 码点加省略号。客户端按可选择的纯文本展示，不把描述当 HTML 或 Markdown。未知工具和旧服务端保留真实名称。

## 边界

调用被记录不证明执行成功或已经完成。现有步骤契约没有结果、退出码、耗时，本轮不推测这些信息；展示日志中选出的命令、代码、路径、查询、URL、描述或提示字段，保留原空白，不倾倒任意参数或 stdout/stderr。输入最多 8KiB、目录最多 4KiB，单轮新增详情共用 128KiB 上限，并计入缓存预算。UTF-8 截断后复制前缀，避免短字符串继续持有巨大的源字符串。界面明确标记超限与旧版本仅有摘要的情况；数组形式的命令按 JSON 展示，保留参数边界，不拼成推测的 shell 命令。OpenCode 当前日志没有工具调用来源。只有 `js` 且缺少描述时无法还原用途。旧服务端已经缓存的历史仍使用旧摘要，正常更新重启后才使用新解析器；本轮不清日志、不重启真实 agent。界面验证使用合成数据，不等于实际执行了对应命令。

## 次要过程信息的收敛（2026-10-20）

本轮用户截图中，一条 `Wait` 同时占了组卡片、条目、空参数框三层，回复操作又像挂在工具框下面。另一张资料窗截图没有显示实际已记录的启动链，首次读取也缺少稳定状态。这些结论来自用户提供的画面，不冒充对竞品 App 的实际操作审查。

[Claude Code 当前桌面说明](https://code.claude.com/docs/en/desktop#switch-view-modes)把 Normal 定义为完整回复加工具摘要，详细调用交给 Verbose；[Carbon 折叠指引](https://www.carbondesignsystem.com/building-blocks/core/patterns/disclosures)提醒避免嵌套折叠互相争夺注意力。资料核对日期为 2026-10-20。借鉴的是信息先后关系，不宣称掌握 Codex 私有桌面界面。

本轮取代前文的大卡片方案：默认收起为灰色摘要，展开为带动作图标的紧凑列表；没有参数就不放空详情，真实长命令仍可滑动和复制。回复操作贴最后一段文字，排在尾随工具之前。资料窗将旧消息事实和按需读取的同会话当前启动链分开，区分加载、不可读和未记录，并用静态占位与稳定高度避免首帧闪烁。上面的数据限制及“不推断调用结果”边界不变。
