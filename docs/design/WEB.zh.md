# Web 浏览器镜像：工作台版（WEB.md）

> 浏览器镜像的权威设计补充。可视参照 [mockup/gtmux-web.dc.html](mockup/gtmux-web.dc.html)（§01 到 §04）。
> mockup 含有提案；下文区分这些提案与当前实现。
> 实现入口 `internal/server/web/`（`index.html` / `app.js` / `style.css`）。底层复用现有
> 契约（`/api/agents · /api/pane · /api/transcript · /api/diff · /api/icon`），浏览器轮询视图数据，按需获取图标。
> 获准的输入使用 `/api/send` 和 `/api/upload`；权限和选项使用 `/api/share` 和 `/api/options`。
> 其他 pane、外观和配对流程使用 `/api/panes`、`/api/theme` 和 `/api/enroll`。
> 所有者资料卡读取 `/api/participant-profile`；可读的外部会话通过 `/api/session/transcript` 读取，始终绑定确切的 session/home。

上传通过 `POST /api/upload?id=<pane_id>` 提交 multipart `file`。Guest 链接须同时满足主机输入授权、pane 授权未失效、该链接拥有目标 pane 的输入权限，与 `/api/send` 一致。主人及其配对设备仍支持不带 `id` 的上传。

## 定位

浏览器屏大、有真键鼠。网页镜像不能照搬手机的单栏布局，它是桌面工作台。左侧 agent 目录按状态和窗口分组，
把列表中的 pane 拖到画板自由排列、缩放，像 tmux 那样自己组合视图。只有获准的 pane 才能输入。

## 红线：布局只改本地，输入按权限开放

真 tmux 能 split/kill/spawn，镜像不假装。「编排窗口与 pane」指的是用户自己的观察布局，
**不改动真实 tmux 树**。服务器确认当前设备有权限后，网页才开放 pane 输入。

**共享页可以打字时，失败必须说话。** 发送被拒时应说明原因并保留草稿，也不能覆盖用户新写的草稿。
`makeComposer` 把普通 HTTP 错误正文显示在输入框下方。403、409 和网络失败路径只在输入框仍为空时放回刚提交的文字；
已有的新草稿保持原样（[#1391](https://github.com/chenchaoyi/gtmux/pull/1391)）。网络失败只能说明送达未确认，网页不能断言没有发出，也不能自动重发。

## 1. 顶栏

gtmux logo · 布局预设下拉（Frontend trio…）· 贴齐网格开关 ·
连接指示（server 名 + 状态点，不用 “live”）· 设置齿轮（跟随系统/浅色/深色、终端字体与字号、回车发送偏好）。

## 2. 左侧目录（session/window/pane 树）

- 工作台读取 `/api/agents`，按 needs-you→errored→working→idle→running 分组，再按窗口分组。同窗口多 pane 会有分组标题；当前标题不能展开或收起。顶部有搜索过滤。
- 单独的「所有 pane」浏览器从窄屏雷达进入（键盘上按 `p` 也行），读取 `/api/panes`，包含普通 shell。它不是工作台左栏。
- 「所有 pane」（2026-10-06）：第一次读回来之前显示品牌加载标记和「正在读取这台 Mac 上的 pane…」，计数行写「正在读取…」；第一次就读失败时写读不到、会再试；读到过之后刷新失败，保留原来的行，计数后加「 · 刷新失败」。agent 行带上 `/api/agents` 给的真实状态徽标——浏览器打开期间雷达自己的轮询停了，所以它和 `/api/panes` 一起读；原来的「on radar」标签去掉了。会话标题显示 pane 数、agent 数，以及每个非零状态的徽标和数量（waiting 是红色），计数行再加「 · N 个等你」。点标题折叠这个会话，栏上有「折叠全部 / 展开全部」；折叠状态存在这个浏览器的 `localStorage`（`gtmux.panes.folded`）里；搜索时折叠的会话里也会列出匹配项。窗口拉宽到工作台宽度以上时，「所有 pane」仍然单独占满屏幕。
- 「所有 pane」中，普通 pane 的名字与另外两块屏同源（`plainLabel` ↔ macapp `PaneLabels.plain` ↔ mobile
  `api/types.paneLabel`）：`title`（跳过整条路径或命令本身）→ `win_name`（除非 tmux 自动改成了命令名）→
  `project` → `cwd` 末段 → `command`。只印命令时一台机器上的 shell 全叫 `bash`，没错，但什么也没区分
  出来。**三份实现、一条链**：改一处必须改三处，偏好顺序在 DESIGN §16。如果包括 command 在内的字段都为空，手机端最后会回退到 pane ID。
- 把左栏一行拖到画板，或双击该行添加 tile。如果该 pane 已在画板上，就把它置前。独立聚焦视图由 tile 的 ⤢ 按钮打开。
- 可收起：头部 ⇤ 收入；收起后画板左缘留带 waiting 计数的小标签（⇥）可重开。
- 可调宽：右缘 col-resize 拖柄，记住宽度（localStorage）。窄于 900px 时，顶层页面改用单栏雷达，不显示工作台。

### Native 启动宿主历史观察

有有效 `launch_host` 时，副标题显示 harness 与宿主，例如 `Codex · sample-client`；
控制端未确认且没有宿主证据时，显示 `Codex · 外部会话`。对话详情列出宿主记录时间，
并保留“当前输入客户端未确认”。来源名称不改变任何操作权限；识别只在 Go 核心完成，
界面不查进程树。提取方法与隐私边界见[agent 接入说明](../guides/agent-integrations.zh.md#外部对话从哪里启动)。
这份观察可能已经过时，不能用它确认当前控制端。

## 3. 自由画板

- 每块 tile = 一个 pane 的实时 xterm 镜像（复用现有 `app.js` 的 xterm 写入 + 滚动锁定）。
- tile：拖标题移动、拖右下角缩放、可叠放/平铺；可选贴齐网格对齐。
- tile 头部：avatar + 角标状态徽章 · 名称 · `对话 / 终端` 显示模式 · 独立的轨迹、Diff 按钮，与模式开关留出间距 · ⤢ 全屏 · × 关闭。
- waiting tile 红边 + 轻脉冲。
- 多 pane = 多个并发 `/api/pane?id` 挂载；`diff` 用 `/api/diff?id`；`对话` 用 `/api/transcript?id`。
- tile 使用绝对定位；缩放某块不会让其他块回流。不拖动而点击标题栏中按钮以外的任意位置，会把该 tile 最大化到画板内；`f` 和 `1–9` 也能最大化。仅工作台可用的命令面板会添加或找到 tile，闪动提示，再把它最大化到画板内。用「还原」或 Esc 返回。这与 ⤢ 打开的独立聚焦视图不同。

小窗较窄时整组控件换行，模式按钮不拆字，输入权限标识始终可见。

## 4. 全屏聚焦（单 pane 细读，mockup §02）

tile 的 ⤢ 或窄屏雷达行，都能打开单 pane 聚焦视图。agent 提供「对话 / 终端」显示模式、模式旁独立的轨迹、Diff 按钮、上/下一个 pane，
以及复制选区或可见屏、跳到最新输出等控件。终端字体和字号统一在设置中调整。两处入口的工具都在原视图上方打开，关闭后保留原对话或终端、草稿和阅读位置。聚焦终端没有换行开关。
Esc 返回此前的顶层视图。

**窄于 800px（手机）。** 顶栏把返回、标题、连接状态和设置放在上层，模式按钮单独一行。身份信息留在标题下方，此宽度不显示上一个/下一个窗格按钮。标题先截断，控件不会被挤出屏幕。只读说明保留在原输入区的位置，外观面板在顶栏下方打开。

**Codex 吸顶提示。** Codex 把屏幕上这一轮的提示固定在第 0 行，按 pane 宽度截断并加「…」。单 pane 终端视图里，对话记录中的完整提示显示在终端上方的提示条里（默认两行，点一下展开，有「复制」按钮），截断的那一行不再进终端。规则和手机一样（见 MOBILE.md）：`app.js` 里有一份 JavaScript 实现，跑同一份用例文件（`mobileapp/src/ui/codexPinnedCases.json`），用同一张按 tmux 实测的字宽表，以检查这些用例和字宽表的一致性。这一行在屏幕上却对不上时，每 4 秒最多拉一次对话记录。工作台的 tile 里不做：tile 放不下第二条栏，那一行原样显示。

## 5. 对话模式 · 宽屏版（mockup §03）

与移动端 `ChatView` 同源（`/api/transcript`：prompt → 中间步骤折叠 → agent 回复），为宽屏重排：

- 全屏只是放大面板里的同一对话组件，不用轮次目录占据阅读列；`j`/`k` 仍可跳转轮次。
- 居中对话列（含内边距最大 900px）：用户气泡靠右并显示用户头像；Agent 气泡靠左并显示官方图标。复制使用图标，有本地化悬停提示、读屏名称和成功/失败反馈，可通过鼠标、键盘和触屏操作。
- 等待卡：`/api/options` 提供解析出的编号和标签。获准输入的读者点击选项，通过 `/api/send` 发送编号，不带 Enter；只读读者能看见选项，但没有发送处理。只有解析出的选项才生成按钮；空结果或失败请求会清掉选项，不凭空生成编号。可输入的对话页直接提供输入框，只读页显示说明。等待也可能是开放式问题，不一定是审批。
- 中间步骤可展开或收起。对话和终端共用多行输入框，默认 Enter 换行、Ctrl/Cmd+Enter 发送，可在设置中选择回车发送；输入法确认不触发发送。附件先暂存，发送时才上传。对话配色跟随页面外观，只提供复制，不提供引用。
- 聚焦页和面板对比完整轮次，包括分段文字与工具详情。内容未变时不重绘，更新时保留步骤展开状态和阅读位置。

## 6. 你的头像 · agent 时代的人类（mockup §03 附）

当前浏览器用固定的青色渐变圆底人形电池 SVG 表示没有发送者归属的用户提示。带发送者归属的轮次改用 HQ 字标，
或发出消息的 agent 头像（`senderAvatarEl`）。颜色不识别个人身份。

mockup 中其余款式（飞升 / 指挥家 / 拍板人 / 队长 / 休息中 / 橡皮图章 / 遛狗反转 / 仓鼠轮）、头像照片上传、emoji 和首字母

## 7. 已交付的布局能力

- 命名预设将 pane ID、位置、尺寸、模式、左栏状态和网格偏好存入 localStorage，由顶栏保存/应用/删除。当前画板也会保存；恢复时只加入当前 agent 响应中仍能找到的 pane。可用的已存布局取决于浏览器存储和站点 origin。
- 等待状态在会话列表中提示；轮询不会自动打开新面板。旧的自动打开偏好不再生效。
- 画板内最大化和独立的单 pane 聚焦视图都已实现；入口和模式区别见 §§3–4。

## 8. 键盘（桌面优先）

工作台中、焦点不在输入控件时：`⌘K` / `Ctrl+K` 打开 pane 命令面板；`1–9` 最大化第 N 块；`f` 切换最前面 tile 的画板内最大化；
`Esc` 还原；`g` 切换贴齐网格；`[ ]` 切保存的预设；`/` 聚焦目录搜索。聚焦对话中 `j/k` 切轮次、`c` 收起步骤；
聚焦终端中 `j/k` 切 pane。这些是网页快捷键，不是原始终端按键直通。

页面快捷键只处理按钮、链接和可编辑区域之外的按键，输入法组字与已处理的事件直接放行。系统组合键保留原有行为，仅工作台明确支持的 `⌘K` / `Ctrl+K` 命令面板例外。雷达选中过一行，也不能抢走当前按钮的 Enter／空格。

## 9. 状态 / 落地

- 雷达采用共享的色/形/字形词汇。连接点随轮询失败改变；tile 请求失败时当前实现保留旧内容。虽然有未使用的 CSS 类，但并未实现逐 tile 的离线灰色遮罩。
- `web/app.js` 已有画板布局引擎（绝对定位、拖拽/缩放、localStorage）、预设和聚焦视图。窄于 900px 时顶层改成 radar→pane。
- 这些布局能力已完成原来的分阶段交付；不包含 §6 提议的头像选择器和 §10 提议的 HQ 指挥台。

## 10. 浏览器语言与 HQ 指挥台提案 · §07 mockup

### 语言：跟浏览器走

这一页跟浏览器的语言走，因为浏览器镜像是唯一一块你交到别人手里的屏。分享链接的收件人是访客，
最不可能读得懂 host 的语言，而这一页曾经漂成了「中文界面 + 少数几处双语」（gate 屏和连接状态提示是双语的，
其余不是），英文读者打开访客链接会看到一页他操作不了的东西（2026-09-07 修）。

它先读 `navigator.languages` 的第一项，再回退到 `navigator.language`，和手机端跟随设备语言一个道理；这里没有 `GTMUX_LANG` 可读，
打开它的人可能根本没装 gtmux。`index.html` 中的中文在 boot 时由 `CHROME` 及 `labelChrome` 的其他赋值重新贴标签。
动态文案使用 `T(en, zh)` 或语言分支，不是每个可见字符串都在同一张表里。

**gate 屏例外，它继续同时显示两种语言**：那是你截图发给能修的人的那块屏。

访问页同时服务 Mac 主人和分享链接的访客：输入框说明可用配对码或分享码，失败提示只说明核对或换码，不假定读者有分享者。空对话页直接提示切换到终端，不把 agent 的会话日志说成 hook 记录。只读状态直接说明该 pane 不允许输入。

`internal/server/webui_test.go` 检查一份明确列出的控件 ID，并扫描附近没有语言切换的中文字符串。这是源码检查，不能证明每个控件都已翻译或翻译内容准确。

标签/按钮的英文大小写按 DESIGN §11 / MOBILE §6 的三档规则（名字与动作句首大写、状态词全小写、
键名全大写小字），这一页落地时直接照抄，别再各写各的，手机端就是这么漂移到「大小写很随意」的。

**提案，不是已交付的 Web 路由：** 左舰队态势（`/api/digest`）、中与 HQ 对话、右派活台账（`/api/tasks`，spawn/reap）三栏，
仅 owner 可用，窄屏竖排。当前 Web 页面没有 HQ 指挥台，也没有调用这些 API；HQ 仍在现有 pane/雷达和发送者归属视图中表示。
不能仅因后端已有对应接口，就把专属指挥台、置顶和断点布局说成已交付。

## 11. 输入能力 + 权限透出 · §08 mockup

网页经 `POST /api/send` 发送，不使用 CLI 的原始 `/api/attach` WebSocket。`/api/share` 返回后，获准的对话与终端视图直接显示输入框，不再重复显示「可输入」标签；只读视图保留权限标签，并用说明代替输入区。获准的读者也可点击聚焦对话中解析出的选项。

owner 可输入其 owner 凭证控制的 pane；guest 需同时满足该分享链接的输入范围（输入⊆可见）、host 的「允许协作者输入」开关，且授权仍有效（`GrantsStale` 为 false）。
顶栏区分 owner 和 guest。服务器在请求时检查权限，撤销后该凭证的新请求会被拒绝。
这条 HTTP 说明不代表独立 CLI attach 流的范围或关闭时序。

`GET /api/share` 返回 `stale:true` 时保留访客连接，在权限条和雷达／目录空态显示「分享授权已失效，请联系所有者重新授权」。列表读取成功后刷新权限，重新授权后提示随之清除。普通访客空态只说明暂无共享 agent；只有所有者会看到启动 tmux agent 的提示。授权失效不显示为链接撤销（`401`）。

## 直连路径下的网页入口

分享链接可以是 `/p<port>#code=...`，无需末尾斜杠。网页会在加载样式和脚本之前设置同源的资源基准地址，静态资源和 API 请求都使用同一个 Mac 路径前缀；站点根目录和显式 `index.html` 入口也受支持。查询参数和凭证片段不会进入资源基准地址。已有分享链接无需更换，访客权限仍由服务器的范围检查决定。

### 共用的模式语义（2026-10-10）

单 pane 聚焦视图和工作台保留“对话 / 终端”显示模式，与手机和 iPad 一致；轨迹和 Diff 直接放在模式开关旁，以间距区分。手机和 iPad App 保留会话工具菜单。
普通 pane 使用终端，旁边直接提供 Diff；打开普通 pane 不会出现空对话，
也不覆盖用户之前选择的 agent 模式。首次默认仍为终端。状态的可见标签和读屏名称
共用 LABEL，不再把正在工作的 agent 读成普通运行进程。浏览器配对使用 Browser
作为通用名称，客户端信息仅展示可获得的粗略信息。

普通 pane 打开聚焦视图后继续使用列表中的 `plainLabel` 标题，副标题不再以空 agent 的分隔符开头。

### 浏览器交互边界

- 输入法正在选字时，Enter 只确认候选词，不发送。普通 Enter 换行，Ctrl/Cmd+Enter 发送；设置中可开启回车发送。
- 原生会话单独列出。可读的外部会话可打开只读的对话与轨迹，其余项标注“仅显示状态”。它们均不能加入画板，也不出现在窗格快速搜索或上一项/下一项导航中；这些操作必须有真实 tmux pane ID。
- 窄屏工具栏折行同样适用于普通 shell，不能因为没有“对话/终端”切换就超出屏幕。
- tile 的叠放层级限制在画板内，不遮挡侧栏恢复按钮等外围控件；最大化后反复点击 tile，也不会盖住“还原”按钮。
- 聚焦对话和 tile 对比完整轮次，包括分段文字、步骤名称和详情。内容未变时不重绘；聚焦对话刷新后保留步骤展开状态和滚动位置。
- 聚焦视图和列表请求绑定发起时的视图及凭证。切换会话或模式、返回列表或权限失效后，旧响应不得再更新页面；即使响应头已返回、内容仍在读取也如此。较新的已完成响应覆盖旧响应，仅发起下一次轮询不会让有效的慢响应失效。
- 权限失效后，访问页清除旧标题、身份和权限标签，停止列表、聚焦视图、选项及 tile 轮询。tile 内容会清空，本地布局保留；重新配对只恢复新权限下的 pane，配对码输入框可以再次使用。

### 临时发送回执
向工作中的 agent 发送文字成功后，输入区简短确认已发送到终端，不承诺何时处理。该信息六秒后消失；再次发送会取消旧计时器，后续的拒绝或无法确认提示保留恢复入口及原文。控制按键不会产生消息等待提示。文案及过期规则与手机/iPad 一致。


## 终端按键面板（2026-10-19）

终端输入条在常用键条中提供固定的「按键」入口，分为导航、功能键（F1–F12）和字符。
既有常用键顺序不变；服务器支持新协议时也使用同一份目录。Ctrl/Alt/Shift 只作用于下一次明确点按，
点按后、关闭面板、切换目标、退到后台或输入权限丢失时清除。不支持的组合禁用，并说明原因。
草稿和附件保持不变，不额外附加回车；主动选择回车或 Ctrl+M 仍会发送回车，字符页说明终端别名。

手机和 iPad 共用组件，最大宽度 480pt，适配安全区和可用高度，可滚动，按钮至少 44pt。
不截获全局实体键盘快捷键或输入法事件。Web 使用同一目录和局部可聚焦对话框。
首期不做宏、修饰键锁定、连发、离线排队；旧服务器保留原有快捷键。

只允许有输入权限的实时 tmux 目标发送。Codex 当前折叠问题提示可提供「查看问题」，
不把进行中改成其他状态；无法识别的键位提示不提供语义操作。回执只说「已发送到终端」，不代表 agent 已执行。
结果未确认时暂停后续发送；主动重试复用原 ID 和上下文，过期或更换目标后不能补发。
详见 [HTTP 契约](../../api/contract.md#typed-keyaction-forms-of-post-apisend) 和 [调研与验证边界](terminal-keyboard-research.zh.md)。

### 执行过程卡片（2026-10-19）

专注对话沿用手机/iPad 的动作名称和中性图标。标题只显示一次调用数，收起时按动作类型汇总。每条先显示简短摘要，点击再查看已记录的工具名、工作目录、输入和来源截断提示（有记录才显示）。委派任务优先显示任务目的；等待只解释明确以毫秒记录的设置，不当作已耗时或完成结果。未知或不完整的参数原样保留，不猜含义。原始输入是可聚焦、限高、可横向滚动的纯文本区域，可单独复制。组折叠按钮有名称和 `aria-expanded`，至少 44px 高。实时更新保留组和条目的展开状态、键盘焦点、输入区域的滚动位置。「折叠全部」放在对话状态旁，用品牌色文字，不加边框。`activity.js` 单独管理展示规则，测试与移动端核对名称、别名和图标表。工作台紧凑小窗仍只显示回复。[来源和边界](transcript-activity-research.zh.md)。


### 会话内交互

等待时就地展示当前提示与安全的编号选项，回答后收起，恢复工作后移除。不设置单独的“交互”模式或重复键盘；未识别的提示沿用输入栏的“按键”和“终端”。App、iPad 与 Web 使用同一个只读当前画面接口，保留 Hook、权限与按键结果边界。见[设计与验证边界](session-interaction.zh.md)。

### 查看待回答问题

服务端提供“查看问题”动作时，通过输入校验后切到当前会话的“终端”，让 Agent 的选择界面可见。不发送输入框里的草稿、不替用户选答案、不改掉用户保存的“对话”偏好。未知、过期、无权限或结果不确定的输入仍沿用现有按键校验与恢复入口。工作台卡片原本只在终端模式显示这类动作。


## 本机工作台与对话轨迹

菜单栏底部「打开本机工作台」通过一次性配对码打开 `http://127.0.0.1:8765`。复用已有服务，或启动 App 自有的本机回环子进程，不开启 tunnel。App 切换远程访问方式时，先释放其本机子进程的端口；退出 App 只停止自己启动的子进程。

独立对话页与工作台面板共用消息、头像、复制和工具摘要。HQ 使用角色字标，串接历史按各轮的来源显示 Agent。对话和终端按权限提供同一个输入框，草稿按窗格隔离；文字还会按服务与凭证保存在浏览器本地，撤销访问时清理草稿和历史输入。

轨迹索引公开的用户消息、助手正文与已记录调用参数；旧记录没有参数时回退到摘要，并显示工作目录与截断提示。搜索覆盖全部已加载记录，支持类型与历史会话筛选、键盘/触摸定位。列表每页最多渲染 200 条；宽视图双栏，窄面板点入详情，关闭后回到原行。轮询保留选择和关闭状态，选字与详情控件焦点保留当前显示版本。沿用窗格及外部会话接口的权限边界，不包含模型请求计时、Token、私有思考和工具输出。轨迹保留阅读空间，对话与终端继续输入。详见[浏览器与原生轨迹交互](transcript-trace.zh.md)。

## 外观与页面身份

外观默认跟随系统，也可选择浅色或深色，偏好保存在当前浏览器。样式加载前先解析偏好，跟随系统时即时响应系统变化。导航、对话、轨迹、控件与弹层使用同一组自适应颜色，终端截图保留服务端配色。

工作台使用 26px 品牌标记、22px 名称及 72px 顶栏，留出清晰边距。侧栏搜索独占会话标题下的一行。内置 SVG favicon 用于浏览器标签，页面标题包含当前会话、视图或工作台/配对状态。

## 图标、文案与交互

界面操作使用内置 Lucide 0.468.0 路径，ISC 许可存于 `internal/server/web/vendor/lucide.LICENSE`。操作图标使用 24 单位绘图网格、20px 显示尺寸和 1.8 单位描边；输入框发送、键盘及历史图标为 24px，信息类权限图标为 16px。导航、展开、关闭、复制和发送不使用字体字符代替。Agent 官方图标与状态标记保留自身身份。

图标尺寸与点击范围分别控制：桌面操作至少 36×36 CSS 像素，触屏至少 44×44，紧凑面板也不缩小操作范围。Tab、Esc、Ctrl C 使用可读文字，方向键使用箭头。这些产品默认值高于 [WCAG 2.2 的最小目标基线](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)，触屏采用 [44px 增强基线](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)。轨迹概览色块同时提供更大的事件行入口。

控件有本地化名称、悬停反馈和可见键盘焦点，关键图标与背景以至少 [3:1 对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)为设计目标。这不是完整 WCAG 合规声明。布局、设置和弹层支持 Esc 关闭并返回焦点；会话行支持键盘打开，轮询不丢失当前焦点。命令面板在关闭前保持键盘焦点。

消息背景仅包住正文。复制位于背景外的透明底栏，用户消息靠右、回复靠左；底栏同时显示已记录的发送时间和来源，缺失或无效时间不显示。复制根据剪贴板实际结果反馈成功或失败。不提供引用。

中文术语统一：产品为「工作台」，画板为「工作区」，tile 为「面板」，Agent 对话为「会话」，tmux pane 为「窗格」。协议标识与命令保持原样。操作与空态使用简洁、具体的表达，如「保存当前布局」「暂无已保存的布局」。不改写 Agent 对话正文。设置中的字体与字号明确标为终端字体、终端字号。

## 行进中的对话

Agent 工作时，独立对话页和工作区面板在输入框上方显示可展开的实时状态条，初始收起。各窗格记住展开选择，停止工作后状态条消失。展开后读取 `/api/pane` 当前画面最后 14 行，与 App 同源，不使用旧对话回复替代；去除终端控制序列，以纯文字显示。时长由状态开始时间与 HTTP 服务端时钟计算，缺失时不显示。

独立对话页同时轮询 Agent 列表，避免进入后的状态停留不变。只有已展开、可见且仍在工作的预览请求画面；失败时提示不可用或内容可能过期，并重试。更新保留草稿、历史阅读位置和向上滚动的预览。请求绑定视图、窗格、工作轮次与凭证，切换后旧响应失效，撤销访问清除缓存。

## 输入框与头像资料

对话、终端和面板共用输入框。控制栏提供 Tab、方向键、回车、退格、Ctrl-C 与 Esc，独立发送终端按键，不改动文字草稿。桌面默认展开输入框，触屏通过键盘按钮展开或收起，使用 44px 点击范围、安全区及浏览器可视视口。展开放大编辑时继续使用同一份草稿，发送按钮保持在键盘上方。

附件入口提供照片、文件、剪贴板图片，触屏增加拍照。粘贴和拖入的文件先暂存，点击发送才上传。图片支持画笔、箭头、方框、实色打码、撤销和清除；导出时按原尺寸合成标记，导出失败后才提供缩小选项。上传显示进度，失败保留文字与附件供重试。附件只留在内存，重新加载页面后需重新选择。

文字草稿、历史输入和常用语按服务与凭证保存在本地。历史输入与常用语只填入输入框供检查，不直接发送。切换身份隔离草稿，撤销访问清除本地输入数据。发送后先显示待记录消息，正式对话记录到达后替换，避免重复。相同内容的重试复用发送标识，网络失败仍表示送达未确认。

用户、发送者、Agent 和 HQ 头像均可打开资料弹层，参考 iPhone/iPad 的头像、身份与分组信息层级。所有者的 Agent 资料卡读取现有 participant-profile 接口，展示已记录的模型、版本、供应商、权限等字段，来源与记录时间可展开查看。消息头像使用当时的 session 和提示时间（`at`），同一供应商的旧会话也不套用当前会话的状态、项目或跳转操作。消息身份缺失及访客连接不会退回查询当前资料。用户消息不推断记录中没有的个人资料或设备。关闭弹层或切换凭证后，旧请求失效。弹层支持 Esc 或关闭图标并返回焦点，手机上从底部呈现。HQ 专属执行链及扩展信息视图仍属于原生 App 能力。

## 会话工具与工作台层级（2026-10-29）

对话和终端是会话的显示模式；轨迹与 Diff 是工具。面板和全屏都在模式开关旁直接提供轨迹、Diff 按钮，以间距区分，
工具使用专属阅读弹层，不替换原模式或输入框。对话与轨迹共享当前记录；终端模式仅在轨迹
打开时读取记录。关闭工具会终止其读取；凭证或视图改变会清除私有工具内容。

调用信息使用无背景卡片的紧凑折叠行，显示动作图标和一次计数。只有摘要的调用不出现空的
详情层；真实输入保留空格、目录及截断说明。真实 supervisor 角色的 HQ 置于状态分组上方，
任务标题不决定身份。下拉框保留原生语义，高度 44px，文字与箭头距边缘 14px，文字尾部
预留 40px。界面控件统一使用系统无衬线字体，代码与终端使用等宽字体。

空工作台提供明确的会话选择入口，并使用为“开始工作”场景单独选取的《沙丘》开篇短引文，
不照搬用户头像资料卡的句子。署名链接指向出版社核对过的原文：
https://sites.prh.com/dune/read-an-excerpt 。中文为节译。

核心把对话图片标记统一转为 Markdown 图片链接。Web 将其显示为文件附件，复用 App 的
所有者文件接口及生成的引用、元数据校验器。点击后才读取，核对大小与摘要，解码前限制
图片尺寸；关闭或失去权限时终止读取并释放私有地址。文件不存在时保留复制路径，不通过
任意路径或外部图片地址回退。

面板和全屏的模式、工具按钮都放在会话标题下方，手机端保持相同顺序。字号只在设置中调整。HQ 头像采用与 App 相同的三格品牌图形，状态另用角标表达。
