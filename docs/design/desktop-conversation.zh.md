# 桌面会话查看

[English](desktop-conversation.md) · **中文**

打开已核实身份的外部 Codex 会话，即可查看已记录的提问、公开回复和工具步骤。
工作中的进展回复会持续更新，无需等最终答案。这是用户主动查看，不会开启 HQ 跟进、
通知或知识采集；跟进设置仍为独立操作。

## 入口与行为

- **Mac：**点击外部 Codex 会话，或在右键菜单选择「查看对话」。历史显示在可调整大小的原生窗口；
  设置图标仍打开跟进设置。窗口隐藏、最小化或应用未激活时暂停轮询。
- **手机：**点击外部 Codex 会话进入只读对话。长按菜单用于跟进设置；访客无法打开对话。
- **iPad：**共用同一查看组件，显示在工作区正文，限制阅读宽度并保留安全区域。
  选择另一会话时替换查看内容。
- **CLI：**`gtmux transcript <session_id> --json` 读取同一份核心数据。
  使用 `--home-id <home_id>` 指定该行的 Codex 目录身份。
  使用 `--etag <revision>`，内容未变时返回 `unchanged:true` 和 `turns:null`。
- **Web：**本批桌面会话仍只提供状态诊断，未接入对话查看。

可见且激活的查看器约每两秒串行读取一次。关闭页面或手机进入后台时取消后续读取，
忽略迟到响应；切换 Mac、Codex 配置目录或会话不会带入旧响应。暂时失败时保留已加载历史并提供重试。
不提供终端、输入框、批准或转入 tmux 操作；继续对话仍需回到原客户端。


当前配置目录中的外部 Codex 条目需要匹配的持久日志才进入实时列表：共享后台 PID 也会服务临时内部调用。
若 hook 早于日志，后续轮询仍能发现，不删除任何观察记录；不按标题、目录、PID 或会话树根合并线程。
Desktop 已观测的打开页面控制信封（只有一个字符串或 null 的 `page_id`）不再作为用户对话。
其后的真实输入保留，格式错误或正文中引用的标签仍可见；其他配置目录的记录不能借用本目录的日志证据。

## Mac 阅读布局

Mac 与手机对话页保持同样的信息层级和操作含义，同时保留原生浅深色外观。紧凑头部
展示 Agent、来源和只读状态；可选的启动观察信息收进信息按钮。每轮只显示一次发言者
和回复者，复用官方图标及现有用户、HQ 头像。核心的 `from` 字段区分 HQ、其他 Agent
和本人，不能把它们都写成「你」。公开 Markdown 使用现有原生阅读组件和字号；时间沿用
HQ 阅读器按十五分钟及跨日分隔的规则。

回复支持逐轮或全部折叠，折叠后保留预览，复制和分享图标仍作用于整轮已记录的文字。
工具组默认折叠，按操作类型显示图标；展开后可逐项查看原始输入、工作目录及截断提示。
长输入支持横向、纵向滚动、选择和复制；记录了调用不等于调用成功。

实现复用现有 Markdown、头像、复制反馈、时间分隔和有界滚动定位组件，不嵌入另一套
手机或 Web 客户端。初次进入及点击最新消息时定位到末尾；阅读旧消息时刷新不抢走位置。
加载与重试有明确状态，所有阅读操作均不增加输入权限或更改跟进同意。

## 数据与边界

文件解析只由 Go 核心负责。精确会话 ID 必须通过 Codex thread 元数据
核实；创建来源不限制查看，身份未核实则拒绝。现代 thread ID 优先于树根 session ID。继续支持 `$CODEX_HOME`。
`GET /api/session/transcript?session_id=<id>&home_id=<home_id>` 仅供所有者和已配对设备使用，读取内容前拒绝访客。
使用公开对话解析器，排除私有分析和注入指引，并合并身份已核实的续接日志文件。
先读取更新标识，再解析内容，解析期间发生追加时下次仍会读取。返回至多 300 轮、512 KiB，
因大小限制省略的轮次会明确报告；条件读取保留已显示历史。

Mac 消费 CLI，手机消费 HTTP 契约，两者均不直接读取 Codex 存储。本批不实现运行时转移。
重新启动 CLI resume 可能成为同一对话的另一个客户端，桌面工具也可能仍依赖原客户端。

[Codex 客户端生命周期方案](codex-client-lifecycle.zh.md) 区分创建来源、当前控制端和持久历史。
这是调研及实施计划，不代表已提供转移操作。

## 验证

核心测试覆盖身份拒绝、访客／所有者权限、中途公开回复、续接文件、更新标识、数据上限及
权限不变。手机测试覆盖共用 Detail 入口、串行轮询、后台／卸载取消、切换 Mac／会话、
失败保留内容和不调用输入能力。Mac 测试覆盖 CLI 参数、串行读取、迟到响应、未激活状态，
以及中英文、浅色／深色合成布局。
真机手机／iPad 布局和 VoiceOver 验收仍待进行；组件和合成窗口测试不代表真机验收。

## Codex 历史保留

共用的 Codex 读取器首次扫描会话日志，最多保留 800 轮已解析对话。工具结果、
上下文压缩快照等非聊天记录不占用对话保留范围，因此大量工具输出不会再因为
超过日志字节窗口而挤掉之前的提问。后续刷新只读取新增的完整 JSONL 记录；
尚未写完的记录等待完整后再解析。已返回的缓存快照不会被修改。日志替换、缩短
或等长重写时会重新读取。

此行为适用于 tmux 和 Desktop Codex 的对话模式。HTTP 返回仍受 300 轮和
512 KiB 限制（最新一轮即使单独超出字节限制也会保留），界面初始展示窗口更小；
这并非无限历史翻页。「全部折叠」为每轮已加载对话保留一个回复预览，不删除历史，
也不会合并不同轮次。终端滚动历史是另一份数据，不受这次读取器改动影响。
此修复需要更新 Mac 服务端，仅更新手机 App 无法生效。
