# 桌面会话查看

[English](desktop-conversation.md) · **中文**

打开已识别的 ChatGPT 桌面版 Work 会话，即可查看已记录的提问、公开回复和工具步骤。
工作中的进展回复会持续更新，无需等最终答案。这是用户主动查看，不会开启 HQ 跟进、
通知或知识采集；跟进设置仍为独立操作。

## 入口与行为

- **Mac：**点击桌面会话，或在右键菜单选择「查看对话」。历史显示在可调整大小的原生窗口；
  设置图标仍打开跟进设置。窗口隐藏、最小化或应用未激活时暂停轮询。
- **手机：**点击桌面会话进入只读对话。长按菜单用于跟进设置；访客无法打开对话。
- **iPad：**共用同一查看组件，显示在工作区正文，限制阅读宽度并保留安全区域。
  选择另一会话时替换查看内容。
- **CLI：**`gtmux transcript <session_id> --json` 读取同一份核心数据。
  使用 `--etag <revision>`，内容未变时返回 `unchanged:true` 和 `turns:null`。
- **Web：**本批桌面会话仍只提供状态诊断，未接入对话查看。

可见且激活的查看器约每两秒串行读取一次。关闭页面或手机进入后台时取消后续读取，
忽略迟到响应；切换 Mac 或会话不会带入旧响应。暂时失败时保留已加载历史并提供重试。
不提供终端、输入框、批准或转入 tmux 操作；继续对话仍需回到 ChatGPT 桌面版。

## 数据与边界

文件解析只由 Go 核心负责。精确会话 ID 必须通过现有 Codex `session_meta.originator`
映射核实；未知身份及终端会话均拒绝。继续支持 `$CODEX_HOME`。
`GET /api/session/transcript?session_id=<id>` 仅供所有者和已配对设备使用，读取内容前拒绝访客。
使用公开对话解析器，排除私有分析和注入指引，并合并身份已核实的续接日志文件。
先读取更新标识，再解析内容，解析期间发生追加时下次仍会读取。返回至多 300 轮、512 KiB，
因大小限制省略的轮次会明确报告；条件读取保留已显示历史。

Mac 消费 CLI，手机消费 HTTP 契约，两者均不直接读取 Codex 存储。本批不实现运行时转移。
重新启动 CLI resume 可能成为同一对话的另一个客户端，桌面工具也可能仍依赖原客户端。

## 验证

核心测试覆盖身份拒绝、访客／所有者权限、中途公开回复、续接文件、更新标识、数据上限及
权限不变。手机测试覆盖共用 Detail 入口、串行轮询、后台／卸载取消、切换 Mac／会话、
失败保留内容和不调用输入能力。Mac 测试覆盖 CLI 参数、串行读取、迟到响应、未激活状态，
以及中英文、浅色／深色合成布局。
真机手机／iPad 布局和 VoiceOver 验收仍待进行；组件和合成窗口测试不代表真机验收。
