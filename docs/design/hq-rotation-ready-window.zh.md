# HQ 维护输入窗口

HQ 工作时，自动提醒不再提前进入 Codex 的后续输入队列，而是在 gtmux 原持久队列保留、合并。只有明确已加载且空闲的线程才能接收一次正常启动；自动路径不插话、不入未来队列、不恢复会话，不在未知或不支持时换通道重发。用户文字和截图入口保持原契约。

已排队、尚未发送的轮换先保留维护窗口，新自动批次不 claim。已经粘贴的自有提醒仍按原精确校验修复，避免把自己的草稿卡死；已发送的轮换允许现有后继交接。读取预约失败只延后自动提醒，不授权输入。快慢 tick 都先处理正常轮换，原身份、回合结束、草稿和双帧保护保留。

超时写一条 important 失败审计，并通过既有桌面通知请求提示；旧请求不重复 reset。这不授权清除已有 Codex 队列或中断真实会话。已经被接受的旧提醒仍可能阻碍现用会话立即轮换，新源码不撤回存量；真实恢复和通知送达另做安装后验收。
