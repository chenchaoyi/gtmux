# 会话文件与文字选择

文件入口放在介绍它的回复里。点击后立即打开预览：顶部为文件名、关闭、信息和分享，
正文先显示读取进度，再展示内容。信息按钮可查看原始路径和文件快照时间；分享使用系统
面板导出原文件。iPhone 全屏展示，iPad 使用系统表单窗口，分享面板锚定在对应按钮上。
失败时保留重试和复制路径入口，不增加独立的文件管理页面。

## 提供文件

报告保存后，由 Agent 或用户在服务器运行下面的命令。会话 ID 必须使用真实的对话 ID，
不是窗格 ID；可从 `gtmux agents --json` 核对。会话带有 `home_id` 时也要指定：

```sh
gtmux artifact add /absolute/path/report.html --session-id SESSION_ID
gtmux artifact add /absolute/path/report.html --session-id SESSION_ID --home-id HOME_ID
```

将输出的 Markdown 链接放进回复。已经发布过的绝对路径链接也能打开对应快照；同一路径
再次发布后，路径链接指向最新快照，固定文件链接仍指向原版本。相对路径保留展示，但不能
据此推断服务器目录。旧链接不会自动发布其目标文件。不要发布凭据、私人资料或用户没有
打算提供给已配对设备的文件。

`gtmux artifact list` 以 JSON 列出已提供的副本；`gtmux artifact remove ID` 移除指定
副本并停止后续下载，原文件及设备已经保存的副本不受影响。私有状态目录的 `artifacts/`
最多保存 256 份、共 240 MiB，单份不超过 30 MiB。达到上限会停止发布，由用户明确选择
移除哪些副本，不扫描历史文件，也不自动清理全局缓存。

## 权限与预览边界

只有本人和全权限的已配对连接可查看，访客分享链接不能读取。服务器只在指定会话与目录
身份下查询已登记副本，不按远端传来的任意路径打开文件。原文件需为本人拥有的非空普通
文件；拒绝末级符号链接、硬链接、常见凭据目录及不支持的扩展名。这些检查不能代替内容
判断，发布者仍需确认文件适合提供。

元数据和内容均沿用当前鉴权连接，凭据只在请求头中，原生下载器拒绝所有重定向。服务器
始终按附件返回，包括 HTML，并设置禁止嗅探、不缓存及沙箱策略。App 校验完整长度与
SHA-256 后才打开私有临时副本。

自包含的 UTF-8 HTML 支持内联脚本、样式和嵌入图片；禁止外部资源、框架、后台线程、表单、
网络连接、新窗口及外部跳转。WebKit 不共享登录数据、没有应用桥接接口，也没有配对凭据。
脚本仍是不可信内容，可能占用资源或在文档内伪造界面，关闭、信息和分享始终由原生界面提供。
拒绝摄像头、麦克风和运动传感器权限请求，禁用元素全屏。iOS 27 起可通过公开的位置权限
回调明确拒绝定位；旧版 iOS 沿用系统定位权限，gtmux 本身不申请定位权限。依赖网络资源的报告可能显示不完整。PDF 和图片通过只读 Quick Look 预览，禁用编辑和外链；
图片解码前有像素上限。文本和 Markdown 暂按可选中的纯文本显示前 512 KiB，分享仍导出完整
原文件。关闭后取消请求并移除该窗口创建的 UUID 缓存；进程异常退出可能留下私有缓存，
不会因此在下次启动时执行大范围清理。

## 选择文字

新 iOS 版本使用同一个 UITextView/TextKit 布局负责富文本和选区：长按、拖动两端手柄，
然后复制。相邻正文段落可以一起选中，代码、表格、标题和工具控件各自独立。原有回复复制
按钮仍复制整份 Markdown。选择期间只固定当前文字及其链接目标，并暂停自动跟随滚动；
Agent 继续工作，取消选区后显示最新内容。原生组件负责横屏、宽度变化和字体缩放后的测量。
折叠的短预览保持原行为，展开后可调整选区。旧安装包回退到原有整块复制方式。

Terminal 的 ANSI 或主题颜色不是对话状态。保留 Markdown 强调，但不从终端颜色推断等待、
成功或批准状态。

## 其他平台与验证

共用的 TypeScript 引用、元数据和请求结构不绑定 iOS。后续 Android 可实现同名的
`GtmuxDocuments.open` 及文字原生组件，但必须遵守相同的权限、下载和隔离约束。目前
Android 保留 RN 文字选择，文件预览显示不支持提示；本轮未新增 Web 或菜单栏原生预览。
详见 [API 协议](../../api/contract.md)。

Go 测试覆盖发布身份、篡改、配额、撤回与权限；Jest 覆盖链接保留、富文本回调及流式选字。
`mobileapp/ios/tests/` 提供不接入真实服务器的原生验收程序，运行
`build-conversation-fixture.sh 私有输出目录` 编译。原生视觉与手势验收、完整 React Native
构建应分别记录，不能相互代替。

原生权限与全屏策略依据 Apple 公开的
[WKUIDelegate](https://developer.apple.com/documentation/webkit/wkuidelegate) 和
[WKPreferences](https://developer.apple.com/documentation/webkit/wkpreferences/iselementfullscreenenabled)，
未使用 WebKit 私有配置。
