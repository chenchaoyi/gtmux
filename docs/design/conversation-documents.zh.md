# 会话文件与文字选择

文件入口放在介绍它的回复里。点击后立即打开预览：顶部为文件名、关闭、信息和分享，
正文先显示读取进度，再展示内容。HTML 默认静态预览；需要图表和按钮时，可点击“开启交互”，
在原生确认框中同意后运行当前文件的脚本；“关闭交互”会恢复静态预览。信息按钮可查看原始路径和文件快照时间；分享使用系统
面板导出原文件。iPhone 全屏展示，iPad 使用系统表单窗口，分享面板锚定在对应按钮上。
读取与失败状态使用居中、可滚动的说明区，完整显示原因和操作按钮。可恢复的错误提供重试，
权限不足时返回会话，格式不支持时可分享已校验的原文件。尚未提供的文件可复制路径或文件
链接；校验完成后才显示顶部分享按钮。说明与按钮支持大字号换行，成功预览的状态栏在
辅助功能字号下纵向排列。不增加独立的文件管理页面。

## 提供文件

会话中的本地文件链接应和本地客户端一样，点击即可查看。服务器先确认链接确实出现在
该会话的公开输入或回复中，并核对会话与目录身份，再自动保存可预览文件的私有快照。
已有历史链接也适用，不需要用户或 Agent 额外执行登记命令。代码块、行内代码、工具参数
和原始 HTML 中的路径不授予文件访问能力，不能替换成另一个文件或会话。支持绝对路径与
本地 file URL；会话中的相对路径需要有可核实的工作目录。

打开路径链接会读取当前版本，固定的 `gtmux-file:` 链接仍指向原版本。临时源文件消失后，
已经保存且仍可访问的快照可继续查看。移除副本会留下私有版本撤销记录，后续点击不会悄悄
重新创建该版本；再次明确执行本地 add 命令可以重新提供。

命令仍可用于固定版本、未出现在会话链接中的文件，或兼容旧服务器：

```sh
gtmux artifact add /absolute/path/report.html --session-id SESSION_ID [--home-id HOME_ID]
```

tmux 使用已鉴权 `/api/transcript` 中所属轮次的 `session_id`，不是窗格 ID 或 tmux 会话名。
外部会话行提供 `session_id`，有 `home_id` 时也要带上。需要固定版本时，返回命令给出的
文件链接。不要提供凭据、私人资料或用户没有打算交给已配对设备的文件。

`gtmux artifact list` 列出私有副本；`gtmux artifact remove ID` 只移除对应快照并停止
后续下载，不影响源文件和设备已保存的副本。最多保存 256 份、共 240 MiB，单份 30 MiB；
达到限制不会扫描历史文件或自动删除其他文件。

## Markdown 阅读

Markdown 默认按格式展示，可选择正文，支持标题、强调、列表、引用、代码块和表格。
宽表格在阅读区内横向滚动，配色跟随系统，iPad 限制阅读列宽度。可切换「查看原文」和
「查看预览」，分享始终导出原始 Markdown。文本与 Markdown 显示前 512 KiB，分享保留完整文件。

报告可以显示同目录及子目录中的本地图片，并打开其中的相关文件。服务器核对已校验父文件
中的实际 Markdown 链接或图片，沿用同一个会话与目录身份；目录树外的路径、符号链接逃逸、
其他会话或已移除的父文件均拒绝。图片通过原生加载器的临时资源标识读取，文档不接触凭据或
应用桥接接口，不加载外部图片。最多 32 个图片引用、两路并发，单图 8 MiB、合计 20 MiB，
解码前检查像素尺寸。关闭、重试或切换原文会取消该窗口的资源请求并清理私有缓存。

## 权限与预览边界

只有本人和全权限的已配对连接可查看，访客分享链接不能读取。服务器按指定会话与目录
身份读取已有副本或经过核实的公开文件链接，不按远端传来的任意路径打开文件。原文件需为本人拥有的非空普通
文件；拒绝末级符号链接、硬链接、常见凭据目录及不支持的扩展名。这些检查不能代替内容
判断，发布者仍需确认文件适合提供。

元数据和内容均沿用当前鉴权连接，凭据只在请求头中，原生下载器拒绝所有重定向。服务器
始终按附件返回，包括 HTML，并设置禁止嗅探、不缓存及沙箱策略。App 校验完整长度与
SHA-256 后才打开私有临时副本。

HTML 默认禁用文件脚本，同时阻止外部资源、框架、后台线程、表单、普通网络请求、新窗口和
外部跳转。WebKit 不共享登录数据，没有应用桥接接口，也没有配对凭据。只有用户在原生确认
框中同意，才会为当前窗口内这个已校验 SHA-256 的文件启用脚本；请求参数不能代替确认。
重新读取会重置许可，文件变化需重新确认，关闭窗口后不会记住。依赖脚本的图表、按钮和
嵌入图片需要交互模式。

**交互模式适用于信任的文件，不保证任意脚本都无法联网。** 本机合成测试已验证，WebRTC
的 STUN/UDP 请求可以绕过 CSP 和普通 WebKit 请求规则，所以确认框会明确提示脚本可能联网。
普通 HTTP 外部资源、外部跳转、应用凭据及桥接仍受限制，原生关闭、信息、分享始终位于文档
之外。脚本仍可能占用资源或在文档内模仿界面。静态模式不会运行这些文件脚本，也不会执行
测试中的 WebRTC 探针。依赖外部资源的报告在两种模式下都可能显示不完整。
拒绝摄像头、麦克风和运动权限，禁用元素全屏。iOS 27 起通过公开回调拒绝定位；旧版 iOS
沿用平台定位权限，gtmux 本身不申请定位权限。
PDF 和图片通过只读 Quick Look 预览，禁用编辑和外链；
图片解码前有像素上限。文本保留可选择的纯文本视图，Markdown 使用上述格式预览。显示前 512 KiB，分享仍导出完整
原文件。关闭后取消请求并移除该窗口创建的 UUID 缓存；进程异常退出可能留下私有缓存，
不会因此在下次启动时执行大范围清理。

## 选择文字

新 iOS 版本使用同一个 UITextView/TextKit 布局负责富文本和选区：长按、拖动两端手柄，
然后复制。相邻正文段落可以一起选中，代码、表格、标题和工具控件各自独立。原有回复复制
按钮仍复制整份 Markdown。选择期间只固定当前文字及其链接目标，并暂停自动跟随滚动；
Agent 继续工作，取消选区后显示最新内容。原生组件负责横屏、宽度变化和字体缩放后的测量。
折叠的短预览保持原行为，展开后可调整选区。旧安装包回退到原有整块复制方式。

Terminal 的 ANSI 或主题颜色不是对话状态。保留 Markdown 强调，但不从终端颜色推断等待、
成功或批准状态。

正文从容器的可用宽度开始排版，不再用 1px 占位。刷新期间保留已确认的高度，忽略旧版本
的测量回调。内容变长时重新使用可用宽度，不沿用短消息的窄宽度；原生层等宽度有效后
再报告高度，相同正文不重复重建。横向代码仍按自然宽度测量，避免完整消息在刷新时短暂
缩成一个字。

## 其他平台与验证

共用的 TypeScript 引用、元数据和请求结构不绑定 iOS。后续 Android 可实现同名的
`GtmuxDocuments.open` 及文字原生组件，但必须遵守相同的权限、下载和隔离约束。目前
Android 保留 RN 文字选择，文件预览显示不支持提示；本轮未新增 Web 或菜单栏原生预览。
详见 [API 协议](../../api/contract.md)。

Go 测试覆盖发布身份、篡改、配额、撤回与权限；Jest 覆盖链接保留、富文本回调及流式选字。
`mobileapp/ios/tests/` 提供不接入真实服务器的原生验收程序，运行
`build-conversation-fixture.sh 私有输出目录` 编译。原生视觉与手势验收、完整 React Native
构建应分别记录，不能相互代替。

原生权限与全屏策略依据 Apple 公开的
[WKUIDelegate](https://developer.apple.com/documentation/webkit/wkuidelegate) 和
[WKPreferences](https://developer.apple.com/documentation/webkit/wkpreferences/iselementfullscreenenabled)，
未使用 WebKit 私有配置。
