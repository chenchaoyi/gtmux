# 界面用语

[English](interface-language.md)

内置界面使用简洁、通用的产品术语，Mac、手机、iPad 和网页保持一致。用户内容、Agent 回复和历史更新说明保留原文。

## 标题、操作与说明

- 配置项用简短名词命名：**桌面通知、标签标记、运行日志、诊断报告、调试日志、链接名称**。
- 操作使用动词，必要时注明对象：**导出…、撤销访问、创建链接**。分享权限统一使用“查看”和“输入”。
- 触发条件、影响和限制放在标题下方的说明中，不用整句行为描述当标题。
- 说明控件实际改变的内容。链接名称只是标签，不代表已验证接收者身份；权限说明应明确所选窗格及授权内容。
- 状态只陈述已有事实，例如“暂无访问记录”“暂无警告或错误”“提交失败”。没有记录不等于从未发生，系统接受通知也不等于横幅已显示。
- 避免设问、拟人化和聊天式提示。“gtmux 记下了什么”改为“运行日志”，“给谁的？”改为“链接名称”。不加无助于操作的安慰和旁白。
- 中英文含义一致。修改显示名称时，保留协议字段、兼容别名、用户引文和历史版本归档。

## 信息层级

控件与说明放在同一行，相关状态、操作和结果集中展示，不为每句说明增加分隔线。独立功能单独分组。浅色和深色下的次要文字都应清晰可读；错误与待处理状态保留真实程度及处理入口。

这些规则只调整展示，不改变授权、通知策略或持久化行为。文案优化不包含实际修改配置或公开诊断数据的授权。
