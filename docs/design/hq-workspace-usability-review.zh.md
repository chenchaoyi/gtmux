## 验证边界

原生模拟数据覆盖加载、保留内容的刷新、空白／错误、历史、来源窗口边界、窄／宽窗和浅／深色。macOS CI 保留七天模拟 PNG。全窗口缓存截图可能遗漏系统合成的侧栏，因此不能证明现场像素或读屏通过；独立资源／表单截图和尺寸测试提供补充。已安装应用实操、实际 VoiceOver 语音仍需单独验收。手机、iPad、Web 和终端不在本轮原生 UI 改动范围内，本轮不发版安装。

历史阅读回归通过 SwiftUI 按稳定消息 ID 定位，先确认确实离开最新位置，再比较非空的前后可见画面。LazyVStack 使用虚拟布局，直接改 NSClipView 原点或比较文档偏移不能证明已滚动到旧消息。
