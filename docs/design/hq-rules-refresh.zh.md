# 只刷新 HQ 规则，不操作会话

[English](hq-rules-refresh.md)

`gtmux hq --refresh-rules` 是独立维护入口，只处理已经存在的受管 AGENTS.md。
它在检查 tmux、资源采样、初始化档案、建联、发送输入、切换窗口及启动 agent 前返回。
不能与其他 HQ 参数组合；帮助仍只读。无需安装 tmux，也不要求 HQ 正在运行。

复用现有版本/语言判断及 `playbookIn`，保留已安装语言；相同或更新版本不重写。
要求当前用户所有的普通可写文件、第一行准确受管标记和已知语言。缺失、旧式/非受管、
符号链接和特殊文件直接拒绝，不顺带迁移。通过既有不跟随链接的私有读取器限读 1 MiB。

与启动/导入共用不等待的文件锁。用排他创建和有界重名处理保存原文，绝不剪掉旧备份；
通过现有私有原子写入器发布 AGENTS.md，不初始化 LOCAL/CLAUDE/notes/knowledge。
发布前再次核对原文件身份与正文。这只能约束共用锁的写者，手工编辑器不参与锁，
不承诺对它们原子 CAS；请先结束手工编辑。发布前失败保留原件；rename 后目录同步失败
可能留下完整新版和原文备份，仍报错，不谎称自动回滚或出现半份新内容。

除普通锁和必要的私有父目录处理外，写入仅限受管文件及新备份。其他文件、会话标记、
队列/输入、服务进程和权限均不属于此动作；普通启动行为不变。此功能不改守则正文或版本。

测试设计及真实先后顺序见 `docs/test/designs/hq-rules-refresh-20261113.json`。
先作者自审设计，再实现测试；须经过独立源码审查与正常发装后，才用已安装入口刷新真实 HQ。
