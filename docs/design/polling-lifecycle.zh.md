# 周期读取生命周期

## 所有权

每条读取通道属于一种资源及当前页面、客户端和凭据。不同资源互不阻塞。
定时器遇到未结束的读取就跳过，不继续排队。写入保留独立回执，不经过这些辅助模块
合并或自动重试。

- 手机/iPad 的 HQ 概览、实时画面、对话，以及 Detail 的画面、对话和选项，复用
  `state/readTask.ts`。离开作用域时取消读取并使旧结果失效；Detail 收到成功发送回执后，
  使此前发起的画面读取失效。
- Web 的雷达、窗格、终端、对话、选项和工作台卡片使用 `app.js` 的读取通道。
  离开页面、切换卡片模式或移除卡片时取消对应读取，继续保留页面、凭据和响应顺序校验。
- 菜单栏的雷达、资源、HQ 阅读器/卡片、保持运行状态和标签顺序分别限制并发。
  周期命令使用 `capturePoll`，用户写入仍走原有路径。

## 边界与失败语义

手机和 Web 的读取包含响应体解析，最长等待 15 秒。取消会传给传输层；即使传输层
忽略取消，旧结果也不能生效或一直占住通道。手机使用原有读取失败反馈；Web 超时会
标记当前连接不可用，后续周期可以恢复。读取审批选项失败时清空选项，避免继续操作旧项。

原生周期命令每条最多运行 15 秒，每个输出流最多 4 MiB，运行中检查输出增长。
超时或输出超限时，仅对已确认独立的子进程组发送 TERM 和 KILL，防止后代进程堆积；
不会向 App 自身进程组发信号。多条命令组成的周期读取，总上限是各命令上限之和。

暂时读不到不代表会话、知识库、历史或用量为空。失败时保留最近一次成功解析的结果；
成功返回的空结果可以清空旧内容。对话、digest 和事件读取遇到 HTTP 5xx 会抛出失败，
不返回空列表。所有者和访客的授权边界保持一致。

## 验证边界

回归测试用延迟响应及受控子进程覆盖并发限制、超时恢复、离页取消、主动失效、旧响应、
输出上限和后代清理；页面测试调用真实 HQ/Detail 读取逻辑及 AgentStore。
变异验证撤回并发保护，要求这些测试失败。浏览器测试使用真实页面资源与模拟 HTTP，
不连接真实窗格。这些检查不能替代真机布局、VoiceOver 或生产网络延迟验收。
