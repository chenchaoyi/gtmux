# HQ 总览：未完成目标与剩余事项

事项是否完成，以工作台明确状态为准。阶段结果、完成一项清理、会话空闲或答复保存，都不等于整个目标达成。HQ 收到可核实的最终报告后及时收口；仍未完成时，评估先说明还差什么/卡在哪里、下一步由谁做什么。只有需要用户完成的具体操作或决定进入“待你处理”，工程阻塞继续由 HQ/执行者跟进并写清下一步。

Mac 总览保留三项预览，列表底部明确显示剩余数量和已显示/总数。交互沿用 iPhone/iPad/Android 已有的底部入口，打开现有完整事项列表，不会发送指令。列表已全部展示时不出现更多入口。完整列表同时展示状态和当前评估。

完成、结束、已合并的事项不进入跟进列表，即使旧预览仍有其 ID。缺失/重复预览用当前明确事项补齐。卡片优先展示当前评估；不把元数据更新时间冒充进展时间。事项状态与执行会话状态分开，读取失败不能显示为会话空闲或已完成。

回归使用合成记录和独立原生窗口，覆盖中英文、浅深色、最小/宽窗口以及 AX 操作。它不替代实际鼠标、VoiceOver 或安装版验收。真实事项由 HQ 通过持久接口核对，不手改台账或根据文字猜完成；本轮不发装、不进行模拟器迁移。
