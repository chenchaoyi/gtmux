# 怎样阅读工具调用

[English](activity-presentation.md)

Activity 的标题说明 agent 在做什么：读取文件、搜索、运行命令、运行代码、编辑文件、访问网页、等待、委派任务。详情保留实际工具名、服务名、参数、结果和状态。不能识别的工具直接显示原名。

实际方法名是 `exec`，也可能在做读取或搜索。Codex 的 `parsed_cmd` 和其他 agent 的适配器提供这些结构化事实。混合操作或无法确定含义的脚本仍显示“运行命令”；不能因为脚本中出现 read、grep 等词就认定它只读了文件。动作标题也不代表执行成功。

App、浏览器 Activity 和 Trace 共用展示逻辑。浏览器文件由 `node mobileapp/scripts/gen-trace-web.cjs` 生成；应修改 `mobileapp/src/ui/`、`mobileapp/src/trace/` 下的源文件，再生成产物。

摘要可以把完整的命令参数数组转成易读的命令。最多解析 8 KiB、64 个字符串参数；数据不完整时保留有长度限制的原始摘要。原始输入不会改变。一条 Exec 读取多个文件，仍是一条调用记录；日志里独立记录的 Run code 和内层调用也都保留，不凭相邻顺序编造父子关系或增加调用次数。

鼠标浏览器里的行高最低 30px；触屏浏览器和 App 的点击区域仍至少为 44px / 44pt。长摘要省略显示，展开后可查看完整记录，也支持键盘操作。

AOP-001 至 AOP-003 记录了标题与原始工具分离、命令摘要边界、各端一致性和显示密度的测试设计。合成浏览器和 RN 用例不能代替真机及读屏验收。后续更改沿用[先设计、再实现的测试流程](test/DESIGN-WORKFLOW.zh.md)。

浏览器最大化窗口的“恢复布局”入口放在标题栏内，和标题、右侧按钮各自占位。窄窗口保留带可访问名称的返回图标；窗口大小变化时，最大化面板随容器调整。点击返回或使用原有 Escape 路径后，恢复原面板尺寸。AOP-004 记录对应的布局与恢复验证。
