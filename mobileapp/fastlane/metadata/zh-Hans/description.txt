在 iPhone 和 iPad 上查看、操作 Mac 或 Linux 服务器中的 tmux 会话。

集中跟进 Claude Code、Codex、DeepSeek Harness 等编码 Agent 和普通终端窗格。离开电脑后，也能查看进度、回复问题和继续操作。

会话与回复
• 查看 Agent 状态和等待你处理的请求。
• 阅读对话与终端输出，发送消息，处理已识别的授权请求和选项。
• 需要键盘输入时，可使用功能键和组合键；查看权限与输入权限分别控制。

HQ 与知识库
HQ 集中跟进多个 Agent，汇总进度，列出待处理事项和操作记录。在你的授权范围内，它可以派发任务，并将可复用的经验整理到本机知识库。

用量与通知
查看支持的 Agent 提供的额度、重置时间和用量记录。在需要回复或任务完成时接收通知，通过实时活动查看会话状态。

连接与分享
支持多台服务器和受限会话分享。分享链接可以撤销，终端输入需单独授权。iPad 提供侧栏布局和外接键盘快捷键。支持简体中文和英文。

开始使用
先在 Mac 或 Linux 上安装免费开源的 gtmux 服务端，再扫描配对码；没有服务器时可以先体验内置演示。可通过自己的网络或 gtmux 隧道连接，会话始终在服务器上运行。安装说明：ccy.pub/projects/gtmux。

隐私
gtmux 不收集数据，无需注册账号。会话和配对凭据保存在你的设备与服务器上。通知经中转服务发往 Apple 推送服务，中转服务只转发、不存储。
