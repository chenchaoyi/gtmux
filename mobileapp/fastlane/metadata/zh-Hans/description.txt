在手机上管理 Mac 上的编码 agent 和 tmux 会话。

在 Mac 上安装 gtmux、配对手机后，Claude Code、Codex 等编码 agent 和普通终端窗格都会出现在手机上。离开电脑，也能跟进进度、回复问题和处理等待中的选择。

HQ（Headquarter）
HQ 是所有 agent 的中控。它持续跟进会话，分析哪里需要你拍板，哪里可以继续推进。你回来时，它会汇报这段时间的变化。需要代你操作时，HQ 只在你授权的范围内行动，每一步都有记录。

HQ 会把工作中值得复用的经验整理进你的本机知识库。遇到相似任务，它会用上过去验证过的做法；你纠正它，或事实发生变化，它也会更新旧经验和自己的处理方式。这样它能逐渐熟悉你的项目和习惯。

会话状态
雷达列出每个窗格和 agent，不同颜色表示不同状态。即使 agent 没有直接接入 gtmux，也能从终端画面识别它的状态。

回复与操作
在手机上回复 agent，或者向终端发送命令。遇到编号选项，可以直接点按钮选择；需要回到 Mac 时，也能把会话切到前台。终端输入受配对权限控制，只读访问不能发送内容。

其他功能
• agent 需要你处理或已经完成时，手机会收到通知。
• 可以从手机直接在 Mac 上新建 tmux 会话。
• 查看额度剩余、最紧的额度窗口和重置时间。
• 锁屏和灵动岛显示当前 agent 的状态。
• 分享指定会话的受限链接，随时可以撤销；输入权限需要单独开启。
• iPad 把雷达放在侧栏，会话在主区域打开；HQ 和待处理事项可以并排查看，也支持键盘快捷键。
• 支持简体中文和英文。

连接方式
gtmux 免费开源，运行在 Mac 上。手机 App、终端、菜单栏、浏览器，以及另一台电脑上的 gtmux attach，都可以连接它。先安装 Mac 版，再配对手机。安装说明：ccy.pub/projects/gtmux。

任意网络访问可使用 gtmux 隧道，无需配置 VPN；也可以通过自己的网络直连。agent 始终在 Mac 上运行。

隐私
gtmux 不收集任何数据，也不用注册账号。会话和 token 只留在你的设备和 Mac 上。通知由你的 Mac 经中转服务发给 Apple 推送服务，中转只转发、不存储。
