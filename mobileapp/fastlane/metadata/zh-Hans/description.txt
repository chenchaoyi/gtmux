gtmux 把 Mac 上 tmux 里跑着的 agent 搬到手机上：Claude、Codex 这类编码 agent，还有它们旁边的普通窗格。在 Mac 上装好 gtmux，手机配对一次，人走到哪儿都知道它们在干什么。

看得见
每个 tmux 窗格、每个 agent 都在雷达上，颜色就是状态：红色在等你，青色在干活，绿色是干完了闲着，灰色是没有 agent 的普通进程。扫一眼就知道该去找谁。有的 agent 没法跟 gtmux 直接通气，gtmux 就读它屏幕上的内容，照样认得出来。

能动手
在手机上回它的问题，或者往终端里发一条命令。它列出 1、2、3 让你选的时候，手机上就是几个按钮。也可以把某个会话调到 Mac 眼前。往窗格里打字得用配对时拿到的 token，能看和能打是两回事。

HQ
HQ（中控）是 gtmux 替你盯全局的那个 agent。它看着所有 agent，你回来时告诉你这段时间变了什么，自己动手只在你划定的范围里。它做过的每件事都按顺序记着，没盯着的那半天可以补着看。

此外
• agent 需要你、或者跑完了才推送，别的时候不出声。
• 额度还剩多少：哪个窗口最紧，还有多久重置。
• 实时活动：当前 agent 的状态留在锁屏和灵动岛上。
• 给同事一个受限链接：只看得到你挑的会话，随时可以收回；能不能打字由你开，默认是关的。
• iPad 上也好用：雷达在侧栏，打开的会话占住正文，HQ 和等你拍板的事并排，接上键盘有快捷键。
• 中文和英文都有。

怎么连上的
手机 app 只是 gtmux 的一个入口，另外几个是终端、菜单栏、浏览器，还有在别的电脑上用 gtmux attach 接过来。gtmux 本身免费开源，跑在 Mac 上；先把 Mac 那头装好，app 才有东西可看。两分钟上手见 ccy.pub/projects/gtmux。
手机连 Mac 走 gtmux 替你开的隧道，不用配 VPN；网络挡住隧道的时候，也可以直接走你自己的网连过去。agent 始终跑在 Mac 上，不会跑到手机上。

隐私
gtmux 不收集任何数据，也不用注册账号。会话和 token 只留在你的设备和 Mac 上。
