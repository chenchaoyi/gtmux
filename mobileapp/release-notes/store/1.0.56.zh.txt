HQ 与 Codex
- HQ 对话现在会列出仍在运行和等你处理的任务，点开清单可直接跳到对应会话。
- 对话会标明消息来自你、HQ 还是其他 agent。HQ 更换 Claude Code 或 Codex 后，历史回复仍显示当时的 agent；时间分隔只在跨天或较长间隔时出现。
- Codex 会话的完成和待处理状态识别更准确，减少误报提醒；HQ 的内部唤醒不会再触发普通会话通知。

连接与线路
- Mac 从休眠恢复、gtmux 重启或连接地址变化后，手机会自动重连。断线时旧列表会变暗，避免把缓存当作实时状态。
- 设置会显示当前线路及这台手机测得的延迟。你可以在手机上换线路；切换失败时仍使用原线路。新版 Mac gtmux 的偏好设置和配对窗口也可选择直连服务器。
- 配对或添加 Mac 失败时会说明原因和下一步，不会一直停在加载中。

终端、附件与分享
- 终端可按 Mac 上的原始宽度显示，左右滑动查看较宽的 Codex 界面；中文内容中的光标位置也已修正。
- 附件最大支持 30 MB。文件过大或上传失败时会明确提示，发送按钮不会一直转圈。
- 分享链接和末尾短码会完整显示，可复制链接、通过系统分享，或复制终端命令；以后还能从链接列表重新打开交付面板。

诊断与辅助使用
- 手机新增本地诊断记录，可在「设置 → 诊断」按天查看、筛选错误、复制或分享。主动分享前，记录只保存在手机上。
- 配对、输入和附件等控件补全了读屏说明；iPad 侧栏也能完整显示 Mac 名称。

HQ、Codex 和线路相关改进需要同时更新 Mac 上的 gtmux。
